# Anderson House Warehouse

The Warehouse is sorted by **function**, not by machine/provider.

Rule:
- Original working files stay where they are.
- Warehouse records point back to the original source.
- Cloud/device names are deployment details, not the primary category.
- A function can appear in only the shelf that describes what it does best.

Current shelves:
1. Text Measurement
2. Text Checking
3. Routing
4. Communications
5. Orchestration

Status words:
- TEST-PRESENT = a matching test file exists in the repository.
- SOURCE-PRESENT = implementation exists but this tidy-up did not independently execute it.
