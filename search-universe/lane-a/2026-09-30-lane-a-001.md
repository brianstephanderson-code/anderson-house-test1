# Search Universe — Lane A — Run 001
Date: 2026-09-30
Pressure test: Washington Irving, *The Legend of Sleepy Hollow*.

## Evidence anchors
- U.S. Copyright Office current rule: works published in the U.S. before 1931 are public domain in 2026.
- Copyright Office Public Records Portal exposes separate record sets by era (1790–1870, 1870–1977, 1891–1978, 1898–1945, 1978–present).
- Library of Congress item 00002099: 1900 *Legend of Sleepy Hollow*, digitized, public domain/free to use and reuse, with LCCN, images/PDF/text and IIIF manifest.
- Library of Congress item 22017103: 1899 *Rip Van Winkle and The legend of Sleepy Hollow*, digitized, notes provenance from the Knickerbocker edition.
- Project Gutenberg ebook 41: *The Legend of Sleepy Hollow*, author Washington Irving, ebook 41, current page says public domain in USA; updated 2026-02-10.
- Project Gutenberg ebook 2048: *The Sketch-Book of Geoffrey Crayon* gives parent-work context.
- Library of Congress Authorities is an authoritative name/subject-heading door.
- WorldCat supplies edition-level bibliographic identifiers and publisher/date differentiation.

## Harvested reusable functions

### A01 AUTHORITY-NAME LOCK — DONE
Purpose: disambiguate creator/entity before deeper searching.
STATE: supplied/variant person, organization, place or title name.
Doors/casts: Library of Congress Authorities; national-library authority catalogs; exact authorized heading.
Transform: resolve aliases/pseudonyms/variant forms to stable authority identity.
DONE: canonical identity + authority identifier + variants.
Stop: one authoritative identity record fits supplied evidence, or explicit unresolved ambiguity retained.
Failure boundary: no authority record / homonyms unresolved.
Fit: books, people, institutions, places, subjects.

### A02 PUBLIC-DOMAIN HARD GATE — DONE
Purpose: establish the legal age gate before production.
STATE: work + publication jurisdiction/date/type.
Doors/casts: copyright office/statute first; secondary explainer only as cross-check.
Transform: apply current dated rule to verified publication facts.
DONE: PD / not-PD / requires-record-search, with jurisdiction and as-of date.
Stop: authoritative rule and relevant facts are sufficient.
Failure boundary: unpublished/foreign/sound-recording/derivative status can require different rules.
Fit: public-domain publishing, images, music, film, archives.

### A03 ERA-ROUTED COPYRIGHT RECORD SEARCH — DONE
Purpose: choose the correct official copyright database rather than generic-searching everything.
STATE: approximate registration/publication era.
Doors/casts: Copyright Office Public Records Portal collections by date range.
Transform: map year -> applicable official record collection(s).
DONE: named official collection and search route.
Stop: all era-overlapping collections checked where needed.
Failure boundary: incomplete metadata/variant titles/names require recast.
Fit: renewal, registration, assignment and historical copyright investigations.

### A04 INSTITUTIONAL DIGITIZED-COPY FINDER — DONE
Purpose: find a scan backed by a collecting institution.
STATE: title/creator/approximate date.
Doors/casts: LOC/national libraries/university repositories; title + creator + date/edition.
Transform: identify item-level record with digital surrogate.
DONE: stable catalog ID + scan/text/PDF/IIIF where offered.
Stop: at least one institution-held digitized edition with sufficient metadata.
Failure boundary: catalog-only record or inaccessible surrogate.
Fit: source-text provenance and facsimile verification.

### A05 EDITION-IDENTITY LOCK — DONE
Purpose: prevent mixing different editions.
STATE: title/author plus candidate copy.
Doors/casts: institutional catalog + WorldCat + title-page scan.
Transform: bind publisher/place/date/physical description/identifier to the copy.
DONE: edition fingerprint.
Stop: independent metadata agrees with the scanned title/copyright matter where available.
Failure boundary: undated/rebound/aggregated records.
Fit: book production, quotations, textual comparison.

### A06 PARENT-WORK / COMPONENT TRACE — DONE
Purpose: recover a story/essay's parent collection and publication context.

### A07 RIGHTS-STATEMENT CAPTURE — DONE

### A08 IDENTIFIER TRIANGULATION — DONE
