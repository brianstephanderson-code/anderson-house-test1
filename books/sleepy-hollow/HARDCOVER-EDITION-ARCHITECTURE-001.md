## BILL — SURVEY

### Inward returns

- 84 stable paragraph anchors
- Reader Edition shell

- pagination probes
- KDP render gate
- provenance and verification functions

Measured prototype counts:
- 5 x 8: 62 pages
- 5.5 x 8.5: 58 pages
- 6 x 9: 53 pages

Existing probes contain no final reader aids and no hardcover illustration program.

### Outward KDP returns
Current official KDP evidence:
- Hardcover is case laminate.
- 5.5 x 8.5 and 6 x 9 black-ink hardcovers support 75–550 pages.
- Hardcover interior contains front matter, body matter, and back matter.
- Interior and cover are separate files.
- Cover geometry depends on final page count and should be generated through the KDP cover calculator/template.
- A free public-domain title must be differentiated; KDP explicitly accepts an illustrated edition containing 10 or more original relevant illustrations.
- Margin requirements depend on page count and bleed.
- All hardcover covers require the KDP cover specification; interior bleed is optional.

### Bill synthesis
The most economical meaningful route is not to pad the source but to create a true **illustrated reader hardcover**.

The current best prototype target is **5.5 x 8.5 in, black ink on cream paper, no interior bleed unless later illustration design requires it**.

Why this candidate:
- It starts closer to the 75-page hardcover floor than 6 x 9.
- It suits a short literary classic better than a larger 6 x 9 trade page.
- It leaves room for a legitimate illustration program and reader-support matter to create a differentiated edition.
- It remains a standard KDP hardcover trim.

Bill status: **SURVEY SUFFICIENT FOR PROTOTYPE.**

## TED — BORGARIZE / BUILD

Ted composes the prototype edition from existing AH functions plus new illustration/layout functions.

### Candidate edition structure

#### Front matter
1. Half-title
2. Frontispiece illustration
3. Title page
4. Copyright / edition / provenance notice
5. Short editor's note explaining this illustrated public-domain edition
6. Optional contents / illustration list if useful after pagination

#### Body
- Irving source text preserved in order.
- Existing stable paragraph IDs remain production metadata and do not intrude on reader text.
- **12 original full-page illustrations** targeted initially.
- Illustrations are placed at genuine scene / mood transitions rather than mechanically every N pages.
- Illustration captions omitted unless they add reader value.
- Reader aids remain subordinate and only enter if separately verified.

#### Back matter
1. Short source/provenance note
2. Illustration credits / AI disclosure only to the extent required or editorially useful
3. Optional brief historical/context note if original and genuinely useful
4. About this edition / Anderson House provenance route
5. Optional author note / Washington Irving context

### Page-building principle
The goal is **not** to hit 75 by filler.

The target is:
- source reading pages: approximately 58 under the previous 5.5 x 8.5 probe;
- 12 meaningful full-page illustrations;
- approximately 6–10 pages of legitimate front/back matter.

Expected prototype range: roughly **76–82 pages**, subject to actual rendering.

This is an engineering estimate only. Final page count must be measured by a real render.

### New functions Ted needs
1. **Illustration Opportunity Mapper**
   - input: stable paragraph/scene map
   - transform: identify visually strong, mood-preserving scenes
   - output: ranked illustration slots with source anchors

2. **Illustration Brief Builder**
   - input: verified scene slot + source context + mood
   - transform: produce a constrained visual brief without rewriting Irving
   - output: provenance-ready illustration specification

3. **Illustration Production Function**
   - input: verified brief
   - transform: generate/draw/acquire original artwork through a permitted route
   - output: original print-suitable illustration + provenance + AI-role classification

4. **Illustration QA Function**
   - input: artwork + source scene + print target
   - transform: check relevance, rights, resolution, tonal consistency, and reader value
   - output: VERIFIED / REJECTED / RECAST

5. **Hardcover Interior Assembler**
   - input: protected text + verified illustrations + front/back matter
   - transform: assemble 5.5 x 8.5 prototype
   - output: print-ready prototype PDF + measured page count

6. **KDP Hardcover Adapter**
   - input: final interior metrics
   - transform: margins/bleed check + exact KDP cover-template geometry
   - output: KDP-compliant interior/cover contracts
