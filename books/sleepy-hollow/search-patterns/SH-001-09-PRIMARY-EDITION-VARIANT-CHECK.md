# SH-001-09 — PRIMARY-EDITION VARIANT CHECK

STATUS: CANDIDATE_REUSABLE_SEARCH_FUNCTION
DATE: 2026-09-30
CORRELATION_ID: sleepy-hollow-research-001:SH-001-09

## Function
When a wording, name, passage, or interpretation may depend on edition history, compare multiple authoritative/public-domain witnesses before treating one wording or editorial presentation as the author's stable text.

## Pattern
TARGET PASSAGE -> EARLY/PRIMARY WITNESS -> SECOND INDEPENDENT EDITION -> EDITORIAL/ANNOTATED EDITION -> VARIANT? -> IF YES preserve variants and investigate provenance; IF NO raise confidence in stable reading.

## Why this expands the Search Universe
A normal search can find a quotation without testing whether the quotation is edition-specific. This pattern deliberately searches across textual witnesses and separates authorial/stable evidence from later editorial framing.

## Sleepy Hollow pressure test
Library of Congress holds multiple digitized editions/witnesses of The Legend of Sleepy Hollow / The Sketch Book, including 1870, 1900, 1901, 1908 and 1911 records. That makes the story suitable for cross-edition verification rather than relying on a single transcription.

## Search doors
- institutional catalogue
- digitized primary/public-domain text
- alternate edition
- edited/annotated edition

## Failure mode prevented
Treating modernization, typo, editorial note, formatting choice, or one-edition wording as if it were unquestionably the stable source text.

## Reuse fit-test
Candidate for books, statutes, historical speeches, manuals, standards, music scores, archival letters, and any source with multiple editions/versions.
