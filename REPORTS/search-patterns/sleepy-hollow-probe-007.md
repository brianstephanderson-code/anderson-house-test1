## Pattern
FOLKLORE-INFLUENCE BRANCH SEARCH

## Function
When a work contains a folklore/supernatural motif, do not assume a single origin. Branch the search across distinct candidate source universes, then test each branch for documented creator contact or textual similarity.

FLOW:
motif in work -> candidate folklore families -> candidate literary sources -> creator/contact evidence -> textual/functional comparison -> rank evidence strength without collapsing branches

## Why reusable
A motif may have multiple independent or blended antecedents. This pattern preserves competing source roads rather than prematurely selecting one.

## Sleepy Hollow pressure test
The Headless Horseman motif opens several source roads. Scholarship represented by Daniel G. Hoffman discusses Irving's American folklore use and also cites earlier scholarship on German sources. The Washington Irving Society likewise describes multiple possible European folklore/literary influences and distinguishes speculation from a more direct Scott/Buerger literary road. This demonstrates the value of branching rather than searching for one supposed origin.
