# Management resolutions

A `<MESSAGE_ID>.resolved` file is an explicit management disposition for an abnormal communication loop that cannot reach ordinary DONE.

Use it only when the blocked work has been deliberately resolved, cancelled, accepted as a completed test, or otherwise dispositioned by the controlling authority.

The Closure Clerk may then close and warehouse the communication while preserving the abnormal return as evidence.

A BLOCKED loop without an explicit resolution remains open.
