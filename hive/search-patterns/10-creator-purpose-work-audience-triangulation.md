# Search Pattern 10 — CREATOR-PURPOSE / WORK / AUDIENCE TRIANGULATION

STATUS: CANDIDATE_REUSABLE
PRESSURE_TEST: The Legend of Sleepy Hollow / Washington Irving

## Function
Search the communication chain from three independent ends:
1. ORIGINATOR EVIDENCE — what the creator said, wrote, drafted, collected, or demonstrably worked from.
2. WORK EVIDENCE — what functions are actually present in the work: framing, mood, pacing, references, narrative devices, contrasts, etc.
3. AUDIENCE / SCHOLARLY EVIDENCE — independently documented reception or specialist interpretation.

Then compare the three. Preserve disagreement. Do not infer creator intent merely from later audience response.

## Search grammar
CREATOR RECORDS -> WORK FEATURES <- AUDIENCE/SCHOLARSHIP
                    |
                    v
              COMMON FUNCTION?

## Why reusable
This can cross communication universes: novel, music, film, speech, illustration, advertising, oral story, etc. It tests whether an apparent function is supported upstream, embodied in the work, and recognized downstream.

## Sleepy Hollow pressure-test evidence
- NYPL Washington Irving collections contain manuscripts, journals, notebooks, correspondence, fragments of The Legend of Sleepy Hollow, and notes/drafts for The Sketch Book. This provides an originator-evidence road rather than relying only on later interpretation.
- Modern Cornell/Oxford scholarship examines Irving's Dutch sources, vocabulary, popular culture, and Hudson Valley folktales, providing an independent specialist road.
- The story's own postscript explicitly complicates the relationship between storyteller, meaning, and audience response, making it useful pressure-test material for separating work evidence from attributed intent.

## Failure mode guarded against
WORK FEATURE -> ASSUMED AUTHOR PURPOSE
or
AUDIENCE RESPONSE -> ASSUMED AUTHOR PURPOSE

Neither is sufficient alone.

## Stop / verification gate
Call a function strongly triangulated only when evidence from the available roads genuinely meets. Otherwise retain it as supported-at-one/two-ends, disputed, or unresolved and recast.

## Search doors demonstrated
- archival creator records
- primary work
- specialist scholarship
- reception/interpretation
