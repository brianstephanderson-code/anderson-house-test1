# Search Pattern Candidate 008 — CROSS-ERA SOURCE TRIANGULATION

STATUS: CANDIDATE / HARVESTED
DATE: 2026-09-30
PURPOSE: Expand the reusable Anderson House Search Universe, using Sleepy Hollow only as pressure-test material.

## Function
When a historical work contains a cultural, geographic, linguistic, or folkloric element whose meaning may have changed over time, deliberately search across different evidence eras rather than treating one modern explanation as sufficient.

## Pattern
1. Anchor the element in a primary/near-primary edition of the work.
2. Search an older historical or institutional source for period context.
3. Search modern specialist scholarship for later reconstruction/reinterpretation.
4. Compare what remains stable across eras and what changes.
5. Preserve disagreements and label inference separately from documented fact.
6. STOP when the purpose is satisfied; do not force agreement between eras.

## Sleepy Hollow pressure test
Library of Congress editions establish the text and bibliographic anchor. Modern Cornell/Oxford scholarship reconstructs Irving's Dutch/New Netherland cultural context and argues that the Hudson Valley tales preserve Dutch life and folk customs amid Anglo-Americanization. Earlier and later scholarship can therefore be compared rather than collapsed into a single timeless explanation.

## Why reusable
Useful for books, law/policy history, genealogy, technical standards, historical terminology, folklore, institutional practice, and any search where present-day explanations may project backward onto older material.

## Failure mode prevented
PRESENTISM: accepting a modern interpretation as though it were contemporary evidence.

## Evidence doors exercised
- Primary/institutional book record: Library of Congress
- Modern specialist scholarship: Cornell University Press / Oxford Academic
- Academic historical scholarship: Fordham dissertation / PMLA where useful
