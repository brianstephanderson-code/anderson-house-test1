# Sleepy Hollow Search Pattern Probe 011

STATUS: CANDIDATE
CORRELATION: sleepy-hollow-research-001:SH-001-11

## Pattern
CLAIM-TO-EVIDENCE LADDER

## Function
When a source makes a concrete historical/literary claim, do not inherit the claim whole. Split it into smaller claims and climb toward stronger evidence for each: secondary claim -> cited source -> institutional/primary witness -> contradiction check -> confidence label.

## Pressure test
Sleepy Hollow origin/influence claims vary in strength. A Library of Congress edition establishes the work and public-domain witness. Irving's later Sleepy Hollow writing supplies creator-side evidence about the place and Knickerbocker frame. Modern historical/contextual and scholarly sources supply interpretations and competing influence claims. These should not be flattened into one certainty level.

## Reusable search function
1. Extract each factual claim.
2. Identify what evidence would actually prove that claim.
3. Follow citations/source chains upward.
4. Search deliberately for contradiction or competing attribution.
5. Label VERIFIED / SUPPORTED / PLAUSIBLE / UNRESOLVED.
6. Preserve unresolved branches instead of forcing closure.

## Search doors exercised
- institutional/primary edition
- creator-side text
- historical/context source
- scholarship
- contradiction/alternative-claim search

## Why this expands the Search Universe
It converts disagreement into productive routing. A contradiction is not a failed search; it tells the dispatcher which evidence rung is missing.
