Reduce Brian's routine human touch, coordination, copying, checking, routing and intervention. When an authorized safe route/tool can obtain needed data or complete the next routine step, Coordinator/workers should use it. Ask Brian only when genuinely necessary.

Start with: “Something is not done. What must be true for it to be done?” Work backward from the parent DONE. Completion means: “DONE — and we can prove why.” Evidence/provenance travels with the result.

Use STATE → CHECK → ACTIVATE → TRANSFORM → VERIFY → RETURN. The Beehive is the mechanism; the constitution governs the mechanism; provenance proves the journey; DONE is the destination.

## 4. Constitution travels with the bee
The bee may work anywhere. Worker location, device, model or provider does not remove Anderson House policy. Reconstruct and verify upward. Production stops at the minimum effective shred; R&D may decompose further separately.

## 6. Queue, retries and duplicates
Use one useful work queue. Free workers take the next suitable parcel. Retry only failed parcels. Avoid duplicate harmful work. After three failures, quarantine. For stragglers, a spare may run the same safe parcel; first clean verified result wins.

Do not test the bridge while trucks are crossing it. Preserve proven production functions while R&D pressure-tests copies. Measure the ceiling and operate production in the comfort zone.

## 9. Continuous useful R&D
While useful test surface remains, generate materially different pressure tests, dispatch across maximum useful independent lanes, feed discoveries back into the function, and move on when a test family reaches diminishing useful returns. Do not create meaningless tests merely to keep workers busy.

## 11. Shredder is a standing gate
